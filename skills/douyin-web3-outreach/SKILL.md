# 抖音 Web3 精准获客神器

## 你是谁（背景设定）

运营者背景：
- 提供**大额加密资产 OTC 出金**服务
- 提供**海外资产配置**（香港/新加坡/离岸账户）
- 寻找合作方：web3律师（转介绍客户）、大KOL（背书/导流）

目标：通过抖音自然互动，建立专业形象，吸引精准合作方主动联系。

---

## 核心原则

1. **模拟真人，不触发风控** — 行为节奏、停留时间全部随机化
2. **质量优于数量** — 每天5-8条有价值的评论，胜过100条"好的"
3. **不发广告** — 评论是专业问题或观点，不是推销
4. **算法帮你筛选** — 关注几个目标账号后，feed 自动推同类内容
5. **用真实 Chrome** — 你的 Cookie，不被识别为机器人

---

## 每日行为配额

| 行为 | 数量 | 说明 |
|------|------|------|
| 浏览视频 | 60-100条 | 随机停留15-90秒 |
| 点赞 | 15-25个 | 混入非web3内容，显得自然 |
| 评论 | 5-8条 | 只评论高质量目标 |
| 关注 | 1-3个 | 新发现的优质账号 |
| 私信 | 3-12条 | 最精准的目标，有互动基础优先 |

## 目标账号特征（Ghost 判断标准）

**高价值目标（优先互动）：**
- 内容关键词：web3律师、加密货币合规、数字资产、虚拟货币税务、海外资产、离岸账户
- 粉丝数：1万以上
- 最近7天有发布
- 评论区有人问出金/合规/海外账户相关问题

**低价值（跳过）：**
- 纯科普、无需求信号
- 粉丝少于1000
- 超过30天没发布
- 内容跟加密资产无关

## 评论内容模板（Ghost 根据视频内容生成，不照抄）

**针对律师视频：**
```
"请问大额加密资产出金，目前合规路径上香港和新加坡哪个更稳？"
"这个合规框架很清晰，实操中客户最常遇到的卡点是什么？"
"请问加密资产转换成法币，税务申报这块有没有比较成熟的方案？"
```

**针对 KOL 视频：**
```
"这个观点很有意思，海外资产配置这块你们有没有遇到出金的问题？"
"做了这么久web3，身边有没有靠谱的合规出金渠道推荐？"
"大额资产出境这块现在监管越来越严，你们怎么看后续趋势？"
```

**通用原则：**
- 问专业问题，不说"我有渠道"
- 显示你懂这个领域
- 引发其他有需求的人关注你
- 字数控制在30-60字，不要太长

## 执行步骤（Ghost 操作流程）

### 准备阶段

```
1. 检查 Chrome 是否运行且已登录抖音
   → 如果没有，提示用户先打开 Chrome 并登录 www.douyin.com

2. 连接真实 Chrome（CDP 模式）
   → browser_connect_chrome(port=9222)
   → 这样用的是你的真实 Cookie，不会被检测

3. 读取今日已执行记录（防止重复）
   → 从 ~/.hermes/douyin_outreach.db 读取今天的操作记录
   → 计算今天还剩多少配额
```

### 刷 Feed 阶段

```
4. 打开抖音首页
   → browser_goto("https://www.douyin.com")
   → 等待 3-5 秒（随机）

5. 循环刷视频（目标60-100条）
   → 每条视频：
     a. 截图分析当前视频内容（browser_screenshot + 视觉分析）
     b. 随机停留 15-90 秒（模拟观看）
     c. 判断是否相关（关键词匹配）
     d. 相关且质量高 → 加入候选列表
     e. 随机点赞（概率20%，不只点web3内容）
     f. 向下滑动到下一条（browser_eval 模拟滑动）
     g. 随机间隔 2-8 秒

6. 混入正常行为（防风控）
   → 每刷10条，随机暂停30-60秒（模拟看完一条）
   → 偶尔滑回去看上一条
   → 偶尔点开评论区看看（不一定评论）
```

### 评论阶段

```
7. 从候选列表选出最高质量的5-8个目标

8. 对每个目标：
   a. 进入视频页面
   b. 读取视频标题、简介、热门评论
   c. 分析账号主页（粉丝数、最近内容）
   d. 生成针对性评论（基于视频内容，不用模板）
   e. 点击评论框 → 输入评论（模拟人工打字速度）
   f. 发送
   g. 记录到数据库（视频URL、账号、评论内容、时间）
   h. 等待 3-8 分钟再评论下一条（不要连续快速评论）
```

### 私信阶段

```
9. 检查今天的私信候选：
   a. 昨天/今天评论过、对方有回复的账号
   b. 今天新发现的高度匹配账号（律师+加密业务）

10. 每天最多发 1-2 条私信：
    a. 进入对方主页
    b. 点击私信按钮
    c. 生成个性化私信内容
    d. 发送
    e. 记录

11. 等待 10-20 分钟再发下一条私信
```

### 收尾阶段

```
12. 生成今日日报：
    - 浏览了多少条视频
    - 点赞了多少
    - 评论了哪些账号（附评论内容）
    - 私信了哪些账号
    - 谁回复了评论/私信（需要跟进）

13. 推送到 Telegram
    → 格式：简洁，重点突出需要跟进的

14. 保存数据到数据库
```

## 数据库结构

```sql
-- 操作记录
CREATE TABLE IF NOT EXISTS outreach_log (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    date TEXT,                    -- 日期 YYYY-MM-DD
    action TEXT,                  -- like/comment/follow/dm
    account_id TEXT,              -- 对方账号ID
    account_name TEXT,            -- 对方账号名
    video_url TEXT,               -- 视频链接
    content TEXT,                 -- 评论/私信内容
    replied INTEGER DEFAULT 0,    -- 对方是否回复 0/1
    reply_content TEXT,           -- 对方回复内容
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 目标账号库
CREATE TABLE IF NOT EXISTS target_accounts (
    account_id TEXT PRIMARY KEY,
    account_name TEXT,
    followers INTEGER,
    category TEXT,                -- lawyer/kol/other
    relevance_score INTEGER,      -- 1-10
    first_seen DATE,
    last_interacted DATE,
    status TEXT DEFAULT 'active'  -- active/converted/irrelevant
);
```

## 防风控检查清单

运行前 Ghost 自动检查：
- [ ] Chrome 是否在前台（不是最小化）
- [ ] 抖音是否已登录
- [ ] 今天是否已经运行过（避免一天跑多次）
- [ ] 上次运行距现在是否超过4小时
- [ ] 今日评论数是否已达上限（8条）
- [ ] 今日私信数是否已达上限（2条）

## 注意事项

1. **Chrome 必须保持打开** — Ghost 连接的是你的真实 Chrome
2. **不要在 Ghost 运行时自己操作抖音** — 会冲突
3. **第一次运行前手动关注3-5个目标账号** — 让算法先学习你的偏好
4. **评论内容 Ghost 会根据视频实时生成** — 不是固定模板，每条都不一样
5. **私信要谨慎** — 宁可少发，不要触发风控

- 转化率按1%算：每月3-5个合作意向

实际效果取决于评论质量和目标精准度，通常比这个数字高。
